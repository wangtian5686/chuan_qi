# 验证清单

## 渲染引擎
- [ ] Canvas 全屏显示，无黑边，窗口缩放自适应
- [ ] 等距瓦片正确绘制，瓦片坐标与屏幕坐标互转准确
- [ ] 相机平滑跟随玩家，地图边缘无穿模/黑边
- [ ] 多精灵按 Y 坐标排序，前后遮挡正确
- [ ] 资源预加载完成后再启动游戏，加载进度可见

## 输入系统
- [ ] 左键点击空地角色寻路移动
- [ ] 左键点击怪物进入攻击范围则普攻
- [ ] 右键施放当前选中技能
- [ ] F1-F8 触发对应快捷栏技能
- [ ] B/C/V 等快捷键正确开关对应窗口

## 三大职业
- [ ] 战士初始高 HP 低 MP，技能含基础剑术/攻杀/刺杀/半月/烈火/野蛮冲撞
- [ ] 法师初始低 HP 高 MP，技能含火球术/抗拒火环/诱惑之光/地狱雷光/魔法盾/冰咆哮
- [ ] 道士初始中 HP 中 MP，技能含治愈术/精神力战法/施毒术/灵魂火符/召唤骷髅/隐身术/召唤神兽
- [ ] 各职业升级时 HP/MP/攻防按成长表正确增长

## 战斗与技能
- [ ] 普攻与技能伤害公式（攻防差、命中、闪避、暴击、幸运诅咒）正确
- [ ] 技能冷却、MP 消耗、学习等级限制生效
- [ ] 投射物（火球/灵魂火符）有飞行轨迹与命中判定
- [ ] AOE 技能（半月/冰咆哮/地狱雷光）正确范围内多目标伤害
- [ ] 召唤技能（骷髅/神兽）生成可控制的友方单位
- [ ] Buff/Debuff（魔法盾、施毒、隐身）状态正确生效与过期

## 怪物与 AI
- [ ] 怪物按地图配置定时定点刷新
- [ ] 玩家进入视野范围怪物追击，脱战回血回原点
- [ ] 怪物死亡按掉落表掉落金币/药水/装备
- [ ] 地面掉落物可拾取进入背包
- [ ] BOSS（沃玛教主/祖玛教主/赤月恶魔）HP 与技能符合预期，掉落经典装备

## 装备与背包
- [ ] 24 格背包支持堆叠、移动、丢弃
- [ ] 装备槽（武器/衣服/头盔/项链/双戒/双手镯/腰带/靴子）正确穿戴/卸下
- [ ] 穿戴装备后属性立即重算生效
- [ ] 装备耐久度战斗损耗，耐久为 0 属性失效
- [ ] 铁匠修理后耐久回满

## 地图与传送
- [ ] 比奇城、盟重省、沃玛寺庙、祖玛阁、赤月峡谷五张地图均可加载
- [ ] 传送光圈/传送 NPC 切图后角色置于正确出生点
- [ ] 城市安全区内禁止 PK 与攻击
